Petroleum trading is my job. I don't write code — I decide what to build and why, and I build it with Claude Code. Since September 2026 my photos, files, calendars and mail have run on one server I pay for. The tools I build for it are on GitHub. I write down the decisions, including the wrong ones.

原油の取引を仕事にしています。コードは書きません。何を作るか・なぜ作るかを決めて、Claude Code と一緒に組み上げています。2026年9月から、写真・ファイル・予定表・メールは自分が払う1台のサーバーで動いています。そのために作った道具はGitHubに置いています。決めたことは、外した判断も含めて書き残しています。
