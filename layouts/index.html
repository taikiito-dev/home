Projects & writing

プロジェクト・執筆

  • Exit Code 0 Is Not Evidence (EN · 日本語)

    終了コード0は証拠にならない (日本語 · EN)

    Eleven documented failures from fourteen months of running my own infrastructure — and the one pattern they share: a tool reported success, and the report was true in a narrow sense and false in the sense that mattered.

    自前インフラを14ヶ月運用して踏んだ障害11件の記録。共通していたのは「道具が成功を報告してきた」こと。その報告は狭い意味では正しく、肝心な意味では間違っていた。

  • Taste Is Not a Reason (EN · 日本語)

    UIを好みで決めない (日本語 · EN)

    Ten rules for deciding an interface by measurement instead of preference — and three decisions I got wrong first, including why I retired every read receipt.

    UIの判断を好き嫌いではなく実測で決めるための原則10個と、先に間違えた3件の記録。既読の印を全部消した理由を含む。

  • Off-Grid (JA)

    A guide series (in Japanese) on reclaiming data sovereignty through self-hosting, written from my own trial-and-error experience — originally to teach my wife.

    データ主権を取り戻すための、非エンジニア向けセルフホスト移行ガイド集。妻に教えるつもりで書いた実体験ベースの記事。

    A side project collecting Singlish phrases and local slang picked up from everyday chats in Singapore.

    シンガポールの日常会話で出会ったシングリッシュ・現地スラングを集めたサイドプロジェクト。
