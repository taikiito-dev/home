Nothing here is general advice. A page leads with the decisions and the dates. Steps and settings go stale as software moves on, so where they run long they live under [Notes](/notes/) instead, and the two pages link to each other. Where a page here does carry commands, it is because the thing it describes is documented nowhere else; it names the versions and dates it was written against, so you can tell what it still applies to.

Only finished pieces live here, written on the assumption that they will not be reworked later. Working records and migration notes live under [Notes](/notes/).
